# Desafio 2 - Classificação de Nível do Herói

Este desafio consiste em classificar o nível de um herói com base na quantidade de vitórias.

## Pré-requisitos

Para executar este projeto, é necessário ter o **Node.js** instalado.

Você pode fazer o download pelo site oficial:

https://nodejs.org/pt-br

## Instalação

Este projeto utiliza a biblioteca `prompt-sync` para receber dados digitados pelo usuário, para instalar

Execute no terminal:

```bash
npm i
